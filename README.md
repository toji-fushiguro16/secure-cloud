# 🔐 Zero-Trust Identity Proxy for Cloud Microservices

A secure cloud application built using Flask, React, and SQLite to support authentication, access control, and Zero Trust security principles.

## 🛠️ Tech Stack
- Python & Flask
- React.js & Vite
- SQLite
- HTML, CSS & JavaScript

## 🔒 Security
- Secure access control
- Environment variable protection
- Zero Trust architecture principles
